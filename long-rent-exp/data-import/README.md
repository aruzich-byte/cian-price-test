# Импорт объявлений (собрано с spb.cian.ru 24.11.2026)

По 13 новых объявлений в каждой категории (вместе с 7 существующими в `js/data.js` — 20).
`offers-<категория>.json` — массив объектов по схеме соседей в `RAW_OFFERS` (ключи — объединение ключей объявлений этой категории, неизвестное — `null`).
`photos-<категория>.json` — `id → [{ src, caption: null }]`, фото в `photos/<категория>/<id>-<n>.webp` (1200px, webp q80).

Категории: `rent-flat`, `buy-flat`, `buy-newflat`, `buy-house`, `rent-house`, `daily-flat`, `daily-house`.

Что важно знать:
- Источник: API поисковой выдачи Циана + страница объявления (характеристики: ремонт, отделка, газ, отопление, канализация, санузел, рейтинг ЖК).
- Под UX-тест: `isGoodPrice: false`, `depositByParts: false` у всех новых; в продаже квартир нет «Евроремонт» + `hasFurniture: true`; `isSuperHost: false` у всех новых посуточных (реальные флаги Циана не переносили, чтобы не менять раскладку теста).
- `repairYear` — `null` (на Циане его нет), `repairGenerated: false`.
- Газ/канализация со значением «Есть» без типа — `null`; газ «Магистральный …» — «Магистральный газ» (без уточнения «по границе/в доме»).
- `addedDaysAgo` — по дате публикации на 24.11.2026.
- Логотипы новых застройщиков — `photos/avatars/dev/<id>.png` (новые файлы).
